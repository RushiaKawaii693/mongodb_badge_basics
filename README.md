# mongodb_badge_basics

One significant distinction between relational and non-relational databases is that relational databases, such as MySQL, store data in structured tables with predefined schemas, whereas non-relational databases, such as MongoDB, store data in flexible documents in JSON-like format, allowing for dynamic and unstructured data.  Another distinction is that MongoDB scales horizontally more easily, making it ideal for massive or frequently changing datasets.  In healthcare, a non-SQL database like MongoDB would be excellent for managing patient health records received from wearable devices, given the data varies in structure and volume across patients and must be updated in real time.  Its versatility and scalability make it ideal for integrating various health variables without constantly changing the database schema.
